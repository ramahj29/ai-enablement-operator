# Selected projects

## HITL job-search and ops agent
Personal system for London junior / graduate roles: scoring, dense one-page CV rendering, pipeline ledger, and weekday digests. Auto-apply only above a score threshold, with hard filters (for example apprenticeships, programmes I have ruled out). Captchas and assessments stay with me.

Skills shown: workflow design, evaluation of failure modes, commercial prioritisation, documentation.

## Campaign response modelling (university)
Python pipeline on a supporter campaign dataset (~3,000 rows): cleaning, feature hygiene with leakage controls, classification, and business-facing error-cost framing for targeting decisions.

Skills shown: data preparation, analytical judgment, translating model output into stakeholder language.

## Trading automation (independent)
Python and AI-assisted coding for market data workflows. I own logic, testing, and debugging rather than pasting unreviewed code.

Skills shown: AI-assisted development with accountability, iteration under uncertainty.

## Portfolio enablement artefacts (this repo)
Playbook, evaluation checklist, Mermaid workflow, agent runbook template, metrics sample, failure-mode log, and tiny Python helpers for scoring and state transitions. Built to show how I would structure junior AI enablement work with HITL gates.

Skills shown: enablement design, quality gates, adoption metrics, risk-aware documentation.
